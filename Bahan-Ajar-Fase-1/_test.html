01

Alur Transmisi & Enkapsulasi Data

Masalah Nyata

Kamu sedang duduk di lab komputer dan mengetik chat WhatsApp: "Halo Bro, mau kirim tugas..." ke teman yang duduk di sebelahmu.

Dua perangkat ini berdekatan, tetapi bagaimana rentetan karakter teks tersebut bisa meluncur melalui kabel, melewati switch, dan muncul di layar laptop temanmu tanpa tertukar dengan data orang lain?
Konsep Inti & Definisi
� Apa Itu Alur Transmisi Data?

Alur Transmisi Data adalah perjalanan sebuah paket data yang dikirim dari perangkat sumber (source) menuju perangkat tujuan (destination) melalui media perantara (kabel UTP, serat optik, atau gelombang radio WiFi). Dalam perjalanan ini, data dibungkus bertahap dengan label pengenal (Enkapsulasi), diperiksa alamat fisiknya oleh switch, dan kemudian dibuka kembali di perangkat penerima (Dekapsulasi) agar sampai tanpa cacat.

Komputer tidak pernah mengirim teks secara mentah. Data harus melewati serangkaian aturan (protokol) yang membungkusnya menjadi paket-paket terstruktur.

Analogi Paket Surat Pos:
  • Isi Surat = Pesan atau file yang kamu kirimkan.
  • Amplop & Resi Pengiriman = Header IP (Alamat logis tujuan) dan Header MAC (Identitas fisik kartu jaringan).
  • Kantor Sortir Pos = Switch Jaringan (Membaca alamat resi tujuan untuk memilih jalur pengiriman yang tepat).
  • Penerima Membuka Surat = Proses Dekapsulasi di komputer tujuan.

Sering Keliru (Miskonsepsi Siswa):

Banyak yang mengira switch memeriksa alamat IP saat meneruskan data antar-komputer. Bukan! Switch Layer 2 tidak peduli dengan alamat IP; switch hanya membaca MAC Address pada frame Ethernet dan mencocokkannya dengan daftar port pada tabel CAM miliknya.

Studi Kasus Nyata

Kasus: Kenapa Switch Baru Mengirim Data ke Semua Port (Flooding)?

Ketika switch baru dinyalakan pertama kali, tabel CAM miliknya masih kosong. Saat HP Siswa di Port 1 mengirim data pertama kali ke Laptop Guru di Port 4, switch belum tahu di mana Laptop Guru berada.

Langkah Penyelesaian Switch (Flooding & Learning):

  • Flooding: Switch menyalin paket data tersebut ke seluruh port aktif (kecuali port pengirim).
  • Learning: Saat Laptop Guru membalas paket tersebut dari Port 4, switch langsung mencatat: "MAC B2:34 berada di Port 4". Pengiriman data selanjutnya akan langsung diarahkan ke Port 4 tanpa membebani port lain!
Quest Pemahaman Tingkat: Dasar
Pada simulasi di atas, informasi apakah yang dibaca oleh Switch pada paket data untuk menentukan port tujuan?
Ingat kembali peran switch di Layer 2 (Data Link) yang menggunakan tabel CAM berbasis alamat fisik kartu jaringan.
Pembahasan Kunci Jawaban
Jawaban Benar: B (MAC Address Tujuan)
Switch Layer 2 membaca header Frame Ethernet, mengekstrak Destination MAC Address, dan mencocokkannya dengan CAM Table untuk mengetahui ke port mana data harus diteruskan. Switch tidak membuka isi pesan pengguna.

02

Subnetting & Pembagian Blok IP

Masalah Nyata di Sekolah / Kantor

Sebuah sekolah SMK memiliki 1 blok IP standar Kelas C: 192.168.1.0/24 yang menyediakan 254 alamat komputer. Awalnya, semua komputer (Lab Siswa, Ruang Guru, Ruang Tata Usaha, dan Server CCTV) digabung menjadi satu jaringan besar.

Tiba-tiba muncul 3 masalah fatal:
  1. Masalah Keamanan (Security): Siswa iseng di lab bisa memindai (scan) dan mengakses komputer bendahara TU serta server nilai guru.
  2. Badai Broadcast (Broadcast Storm): Setiap kali ada 1 komputer mengirim sinyal pencarian printer, seluruh 254 komputer dipaksa menerima sinyal tersebut sehingga jaringan melambat.
  3. Pemborosan Alamat IP: Ruang server yang hanya butuh 4 alamat tetap memakan 1 jaringan besar.
Konsep & Manfaat Subnetting
� Apa Itu Subnetting?

Subnetting adalah teknik membelah satu blok jaringan besar (Network ID) menjadi beberapa sub-jaringan yang lebih kecil (Sub-network / Subnet) yang saling terpisah secara logis. Hal ini dilakukan dengan cara "meminjam bit" dari porsi Host ID untuk dialihkan menjadi porsi Network ID.

Manfaat Utama Subnetting di Dunia Kerja:

  • 1. Mengisolasi Keamanan: Komputer siswa di Subnet 1 tidak bisa sembarangan mengakses komputer keuangan di Subnet 3 tanpa izin firewall router.
  • 2. Mencegah Jaringan Lemot (Memecah Broadcast Domain): Sinyal broadcast di Lab Siswa tidak akan bocor ke Ruang Guru.
  • 3. Efisiensi Ruang Alamat IP: Alamat IP publik maupun privat dialokasikan sesuai jumlah kebutuhan nyata tanpa banyak alamat terbuang.
Analogi Gedung Sekolah:

Satu lantai gedung tanpa sekat membuat suara bising terdengar ke semua orang dan siapa saja bebas masuk ke ruangan orang lain. Subnetting adalah memasang dinding partisi menjadi 4 ruang kelas mandiri. Setiap kelas memiliki pintu keluar masing-masing (Gateway Router) untuk keluar masuk.

Dasar Biner: Dari Mana Asal Angka Subnet Mask?

Alamat IPv4 terdiri dari 32 bit angka biner yang dibagi menjadi 4 bagian (oktet). Setiap oktet berisi 8 bit. Masing-masing bit memiliki bobot kelipatan dua dari kanan ke kiri:

Contoh: Kenapa Prefix /26 menghasilkan Subnet Mask 255.255.255.192?
Prefix /26 artinya ada 26 angka 1 di awal. Tiga oktet pertama berisi 8+8+8 = 24 bit penuh (255.255.255).
Pada oktet ke-4, tersisa 2 bit bernilai 1: 11000000.
Nilai desimalnya = Bit 1 (128) + Bit 2 (64) = 192!

Langkah Perhitungan Subnetting Lengkap

Mari kita hitung bagaimana membagi jaringan 192.168.1.0/24 menjadi 4 Subnet untuk 4 ruangan di sekolah:

1

Tentukan Berapa Bit yang Harus Dipinjam

Alasan: Setiap 1 bit biner yang dipinjam melipatgandakan jumlah subnet sebanyak 2 kali (1 bit = 2 subnet, 2 bit = 4 subnet, 3 bit = 8 subnet).
Kebutuhan: 4 Subnet 2 bit dipinjam menghasilkan: 2 x 2 = 4 Subnet (Pas!) Prefix Awal : /24 Bit Pinjaman: + 2 bit Prefix Baru : /26 Subnet Mask : 255.255.255.192
✓ Hasil: Prefix baru adalah /26
2

Hitung Jumlah Komputer (Host) yang Bisa Masuk per Subnet

Alasan: Total panjang alamat IP adalah 32 bit. Setelah 26 bit dipakai untuk Network, sisa bit host adalah 6 bit. Dari total kombinasi tersebut, 2 alamat wajib dikurangi karena alamat pertama adalah nama jaringan (Network ID) dan alamat terakhir untuk panggilan serentak (Broadcast ID).
Sisa bit host = 32 bit - 26 bit = 6 bit host Total kombinasi alamat = 2 pangkat 6 = 64 alamat Alamat yang bisa dipasang ke komputer = 64 - 2 = 62 Komputer
✓ Hasil: Maksimal 62 Komputer per Subnet
3

Hitung Ukuran Blok (Jarak Antar Subnet)

Alasan: Untuk mengetahui di angka berapa saja Network ID berikutnya dimulai, kita kurangi angka total 256 dengan angka terakhir subnet mask.
Ukuran Blok = 256 - Nilai Oktet Terakhir Mask = 256 - 192 = 64 Artinya Network ID akan melompat setiap kelipatan 64: Subnet 1 = 0 Subnet 2 = 0 + 64 = 64 Subnet 3 = 64 + 64 = 128 Subnet 4 = 128 + 64 = 192
✓ Hasil: Ukuran Blok = 64

Quest Perhitungan Tingkat: Menengah
Jika jaringan 192.168.10.0/24 dibagi menjadi 4 subnet sama besar (prefix /26), berapakah alamat Broadcast ID untuk Subnet ke-2?
Subnet 2 dimulai dari Network ID 192.168.10.64 dan Subnet 3 dimulai dari 192.168.10.128. Broadcast adalah 1 angka tepat sebelum Network ID subnet berikutnya.
Pembahasan Kunci Jawaban
Jawaban Benar: B (192.168.10.127)
Subnet 2 memiliki Network ID 192.168.10.64 dan ukuran blok 64. Subnet 3 dimulai di 192.168.10.128. Maka alamat Broadcast Subnet 2 adalah satu angka sebelum 128, yaitu 192.168.10.127.
